# LLM Prices — Compare Studio (Tesserae front-end)

This is the source for the site served from `wwwroot/`. It is a
[Tesserae](https://github.com/curiosity-ai/tesserae) app (C# compiled to JavaScript via the
[h5](https://github.com/h5dotnet) compiler) that renders the "Compare Studio" pricing explorer:
a log/log input-vs-output price scatter, a token-mix Compute panel with a compare tray, and a
blended-cost table of every model.

Pricing data comes from the [`simonw/llm-prices`](https://github.com/simonw/llm-prices) project
and is read at runtime from `current-v1.json` (generated by `scripts/build.py`).

## Building

The project's `h5.json` sets `"output": "../wwwroot/"`, so building compiles the page **into
`wwwroot/`**, emitting `index.html`, `app.min.js`, the runtime bundles and the `assets/` folder
(CSS, fonts and logos).

```bash
# one-time tooling
dotnet tool install --global h5-compiler
export PATH="$PATH:$HOME/.dotnet/tools"

# compile the site into wwwroot/
dotnet build app/LlmPrices.csproj -c Release

# generate the pricing JSON the page fetches
python3 scripts/build.py
cp current-v1.json favicon.png wwwroot/
```

Then serve `wwwroot/` and open it in a browser:

```bash
dotnet tool install --global dotnet-serve
dotnet serve --port 5000   # from wwwroot/
```

The generated output (`wwwroot/index.html`, `wwwroot/*.js`, `wwwroot/assets/`, ...) is
git-ignored; the Cloudflare Pages deployment runs the same build (`build.sh`) before publishing
`wwwroot/`.

## UI structure

- A dark navy navbar with the [curiosity.ai](https://curiosity.ai) logo and an About dialog.
- **Price landscape** — an SVG scatter of input price (x) vs output price (y) on log scales,
  one dot per model coloured by vendor, with a shaded "best value" region below the median
  prices. Clicking a dot toggles the model in the compare tray.
- **Compute** — token-mix inputs (input / cached / output tokens per request) and the compare
  tray, which shows each selected model's blended cost with a relative-cost bar and calls out
  how much cheaper the cheapest pick is.
- **All models** — a sortable, searchable table of every model with input / cached / output
  prices and the blended cost of the current token mix; ticking a row adds it to the tray.

## Layout

- `src/App.cs` — page shell, navbar, scatter chart, compute panel + tray, table, About modal.
- `src/PriceData.cs` — fetches and parses `current-v1.json`.
- `src/Styles.cs` — injected CSS (theme variables, navbar, cards, chart, table).

## Logos

The Curiosity logo lives at `app/h5/assets/img/curiosity-logo.svg`; provider logos in
`app/h5/assets/img/logos/` are still shipped to `assets/img/logos/` at build time, although the
UI currently renders vendor-coloured initial tiles instead.
