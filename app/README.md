# LLM Prices — Tesserae front-end

This is the source for the `index.html` page served at the repository root. It is a
[Tesserae](https://github.com/curiosity-ai/tesserae) app (C# compiled to JavaScript via the
[h5](https://github.com/h5dotnet) compiler) that renders the LLM pricing calculator and model
price table.

Pricing data comes from the [`simonw/llm-prices`](https://github.com/simonw/llm-prices) project
and is read at runtime from `current-v1.json` (generated by `scripts/build.py`).

## Building

The project's `h5.json` sets `"output": "../"`, so building compiles the page **into the
repository root**, replacing `index.html` and emitting `app.min.js`, the runtime bundles and the
`assets/` folder (CSS, fonts and provider logos).

```bash
# one-time tooling
dotnet tool install --global h5-compiler
export PATH="$PATH:$HOME/.dotnet/tools"

# compile the site into the repo root
dotnet build app/LlmPrices.csproj -c Release

# generate the pricing JSON the page fetches
python3 scripts/build.py
```

Then serve the repo root and open it in a browser:

```bash
dotnet tool install --global dotnet-serve
dotnet serve --port 5000   # from the repository root
```

The generated output (root `index.html`, `*.js`, `assets/`) is git-ignored; the GitHub Pages
workflow (`.github/workflows/pages.yml`) runs the same build before deploying.

## Provider logos

Logos live in `app/h5/assets/img/logos/` and are copied to `assets/img/logos/` at build time.
Most were taken from Curiosity's icon set; the providers without one (deepseek, minimax,
moonshot-ai, qwen, xai) use simple brand-coloured marks. `generic.svg` is the fallback for any
unknown vendor.

## Layout

- `src/App.cs` — page shell, calculator, sortable/searchable table, About modal, dark mode.
- `src/PriceData.cs` — fetches and parses `current-v1.json`.
- `src/Styles.cs` — injected CSS (theme variables, cards, table).
